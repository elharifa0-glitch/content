# استوديو الشغل

نسخة الموقع دي بتشتغل من أي جهاز أو موبايل، بحساب دخول حقيقي وقاعدة بيانات، من غير الاعتماد على أي مفتاح API خارجي — كل ميزات الذكاء الاصطناعي اتشالت والموقع دلوقتي معتمد على البيانات اللي بتدخلها إنت بنفسك.

الخطوات محتاجة حوالي 15-20 دقيقة أول مرة، وبعدين الموقع هيفضل شغال لوحده.

## الخطوة 1: اعمل حساب Supabase (قاعدة البيانات + تسجيل الدخول)

1. روح على [supabase.com](https://supabase.com) واعمل حساب مجاني.
2. دوس **New Project**.
3. اختار اسم للمشروع وباسورد لقاعدة البيانات (احفظه في مكان آمن).
4. استنى دقيقتين لحد ما المشروع يخلص إعداد.

## الخطوة 2: جهّز جدول البيانات

1. من القايمة الجانبية جوا Supabase، دوس **SQL Editor**.
2. دوس **New query**.
3. افتح ملف `supabase-schema.sql` اللي جوا المشروع ده، انسخ كل اللي فيه، والصقه في المحرر.
4. دوس **Run**.

ده هيعمل جدول واحد اسمه `user_data` بيحفظ بيانات كل مستخدم لوحده، وميقدرش حد يشوف بيانات حد تاني.

## الخطوة 3: فعّل تسجيل الدخول بالإيميل

1. من القايمة الجانبية، روح **Authentication > Providers**.
2. تأكد إن **Email** مفعّل (بيكون مفعّل افتراضيًا).
3. لو عايز تجرب بسرعة من غير ما تتأكد من الإيميل كل مرة: روح **Authentication > Settings**، وقفّل **Confirm email**. (تقدر ترجعها تاني بعدين لو الموقع هيبقى عام لناس كتير.)

## الخطوة 4: خد بيانات الاتصال

1. روح **Project Settings > API**.
2. هتلاقي **Project URL** و **anon public key** — انسخهم.

## الخطوة 5: جهّز المشروع على جهازك

محتاج [Node.js](https://nodejs.org) متثبت على جهازك (نسخة 18 أو أحدث).

```bash
# جوا فولدر المشروع
cp .env.example .env
```

افتح ملف `.env` اللي اتعمل والصق فيه القيم اللي نسختها من الخطوة 4:

```
VITE_SUPABASE_URL=https://xxxxxxxxxxxx.supabase.co
VITE_SUPABASE_ANON_KEY=eyJhbGc...
```

بعدين:

```bash
npm install
npm run dev
```

هيفتحلك لينك زي `http://localhost:5173` — افتحه في المتصفح، اعمل حساب، وجرّب الموقع محليًا الأول قبل النشر.

## الخطوة 6: انشر الموقع على Vercel (مجاني)

1. اعمل حساب على [vercel.com](https://vercel.com) (تقدر تسجل دخول بحساب GitHub مباشرة).
2. ارفع فولدر المشروع ده على [GitHub](https://github.com) (لو مش عارف تعمل ده، قولّي وهوريك خطوة بخطوة).
3. جوا Vercel، دوس **Add New > Project**، واختار الـ repo اللي رفعته.
4. قبل ما تدوس Deploy، افتح **Environment Variables** وضيف نفس المتغيرين من ملف `.env`:
   - `VITE_SUPABASE_URL`
   - `VITE_SUPABASE_ANON_KEY`
5. دوس **Deploy**.

بعد دقيقة أو اتنين هيديك لينك زي `your-project.vercel.app` — ده الموقع بتاعك شغال أونلاين، تقدر تفتحه من أي جهاز أو موبايل.

## أسئلة شائعة

**هل الداتا هتفضل موجودة لو مسحت الكاش أو غيّرت جهاز؟**
أيوه — الداتا كلها بقت في قاعدة بيانات Supabase مش في المتصفح، فتقدر تدخل من أي جهاز بنفس الإيميل والباسورد وتلاقي كل حاجة موجودة.

**هل ده مجاني؟**
Supabase وVercel عندهم باقة مجانية سخية كفاية لاستخدام شخصي أو لعدد صغير من المستخدمين. لو الاستخدام كبر جدًا ممكن تحتاج تدفع، بس مش متوقع ده يحصل قريب.

**هل أقدر أضيف الذكاء الاصطناعي تاني بعدين؟**
أيوه، لكن هيحتاج شغل إضافي (سيرفر صغير وسيط يحمي مفتاح الـ API بتاعك، بدل ما يتحط في كود الموقع مباشرة). قولّي لو عايز تضيفها بعدين وهساعدك.

**نسيت الباسورد بتاعي؟**
من صفحة تسجيل الدخول جوا Supabase Auth ممكن نضيف خاصية "نسيت الباسورد" لاحقًا لو احتجتها.
